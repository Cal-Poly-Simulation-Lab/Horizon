# Horizon project website

This is a static website published with GitHub Pages from the `docs/` folder on the `main` branch. It has no build step or external runtime dependencies.

## Enable GitHub Pages

In the repository settings, open **Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/docs`, then save. GitHub Pages will publish the site at:

<https://cal-poly-simulation-lab.github.io/Horizon/>

## Updating the site

Edit `index.html` and `styles.css` directly. Images in `docs/assets/` are copies of project artwork from the repository's top-level `assets/` directory; when replacing an original, update its website copy as well. Tutorial and publication links point to the project wiki.
